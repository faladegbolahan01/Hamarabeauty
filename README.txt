HAMARA BEAUTY - FOUR PAGE FILE PACK
Contains about/services/gallery/contact HTML, CSS and JS (12 files).
Copy all 12 files into the same project folder as index.html and shop.html. These pages do not replace your shop or checkout files.
IMPORTANT: In services.js and contact.js, replace 2340000000000 with the owner's WhatsApp number in international format, digits only. Example Nigerian 08012345678 becomes 2348012345678.
Gallery photos are illustrative remote image placeholders; replace with the makeup artist's own portfolio photos before launch.
These pages use a coordinated cream/brown theme based on the Hamara Beauty checkout confirmation styling and available project snippets. The full index.html/style.css were not supplied in this turn, so verify visual consistency with your homepage before launch.
